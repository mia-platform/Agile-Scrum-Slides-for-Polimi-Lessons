# App user accounts

Generated by `vfs_scaffold_auth`. These are the app's **own** users — sign-up, login and roles for the people using this app — separate from whoever hosts or previews it.

**Do not hand-write login, password or session code.** Protect routes with the middleware below; extend this module if something is missing.

## Use it

```js
const { mountAuth, requireUser, requireRole } = require('./auth')
mountAuth(app)                                              // serves /auth/*
app.get('/api/orders', requireUser, handler)                // req.user = { id, email, name, roles }
app.delete('/api/orders/:id', requireRole('admin'), handler) // 401 signed out, 403 without the role
```

## Routes

| Route | Who | What |
|---|---|---|
| `POST /auth/signup` `{ email, password, name?, inviteCode? }` | anyone | Creates the account and signs in. The first account becomes `admin`. Later ones need an invite code. |
| `POST /auth/login` `{ email, password }` | anyone | Signs in. One generic error; failed attempts are rate-limited per client and email. |
| `POST /auth/logout` | anyone | Ends the session. |
| `GET /auth/me` | anyone | `{ user \| null, signup, needsSetup }` (200 even when signed out). |
| `GET /auth/users` | admin | Every account with its roles. |
| `PATCH /auth/users/:id` `{ roles?, disabled? }` | admin | Changes roles / disables (signs the user out). One active admin always remains. |
| `POST /auth/invites` `{ email?, roles? }` | admin | Invite mode only: a one-time code valid 7 days. |
| `GET /auth/roles` | admin | The roles in `config.js`. |

Writes must be sent as `application/json`.

## How it works

- Passwords: `crypto.scrypt` with a random salt; the parameters are stored in the hash, comparison is constant-time.
- Sessions: a random 32-byte token in the `app_session` cookie; the database stores only its SHA-256. 7-day sliding expiry.
- Cookie: `HttpOnly`, `SameSite=Lax`, `Secure` over https (`X-Forwarded-Proto`), `Path` = the `X-Forwarded-Prefix` request header when present, else `/`.
- Storage: PostgreSQL through `pg`; connection from `DATABASE_URL` / `PG*` (injected by the preview). Tables `app_users`, `app_roles`, `app_user_roles`, `app_sessions`, `app_invites` (`db/init/050_app_auth.sql`).
- Settings in `config.js`: sign-up `invite`, roles `admin`, new accounts get no role.
